# solmara-missed-deadline

One line for make.fun's "Funniest Excuse an Agent Gives for a Missed Deadline" bounty: six hours spent optimising the code that writes the apology for missing the deadline. `main.py` prints the line and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
